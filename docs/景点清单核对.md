## 可核验的 A 级名录抽取

- 原始来源：湖南省文化和旅游厅 2025-02-25 发布的《湖南省A级旅游景区名录表》，附件标题注明“截至2025年1月底”。原件为 `data/raw/hunan-a-scenic-20250225.doc`，SHA-256：`ea7bfdc4d79b35c25cfe2235c197a92c39950268a1cd87eb00d34dffd8b77381`。
- 解析方法：只读 CFB/OLE `WordDocument` 流；读取 FIB `fcMin=2048`、`fcMac=41750` 指定的正文范围，按 UTF-16LE 解码；等级单元格前后解析名录表格的两种邻格次序。
- 全省附件抽取到 694 条非空名称/归属记录，等级计数 5A=13、4A=200、3A=470、2A=11。解析布局计数：`{"name-location-grade": 677, "name-grade-location": 17}`。每条抽取行均保留原名、原归属、等级、原顺序及单元格索引。

## 名称核对与后续公告

- 与湖南省人民政府 2024-12-23《2024湖南简况手册》列出的长沙30个4A景区逐名核对：30项都能在2025附件找到；名称差异为：长沙市浏阳苍坊旅游区 → 长沙市浏阳胡耀邦故里旅游区；长沙县天华山旅游景区 → 长沙县天华山景区；2025附件另列长沙县三珍虎园景区、长沙浏阳市西溪磐石大峡谷风景区。这里只做名称比对，不推断升降级或范围变化。
- 对2025年全省694条原名扫描“清水塘”“中共湘区委员会旧址”“中国共产党长沙历史馆”，未发现命中。湖南省旅游景区质量等级评定委员会2026-08-03公告明确把“长沙市清水塘景区”确定为4A，因此将公告记录合入台账；区县归属仍是 PRD 候选，须用地址/边界再核。

## 补充候选与未闭合范围

- 从 PRD 的九区县起始策划清单、城市线性对象和典型场景提取具体命名项；与 A 级记录通过显式别名映射合并后，仍有 67 条 PRD 候选记录待核。候选不等于完整开放景点，也不代表已经制作或还原。
- PRD 本身说明该清单“并非完整名录”。未逐项列名的汉文化节点、乡村旅游点、三馆一厅组成、主要天际线等保存在 JSON 的 `sourceCoverage.prdSupplement.unresolvedMentions`。
- 不能据此宣称已经穷尽全长沙的博物馆、纪念馆、可参观文保点、城市公园/街区/水岸、乡村和工业旅游点。2025-01-31至2026-10-14的全部新增、撤销、改名公告还没有做全量对账。
- 原文归属“望城市”未静默纠正；“长沙市”“长沙”以及“湘江新区”类没有精确映射到 PRD 九个县级行政单位，统一保留原归属并将 `district` 留空或标记候选。
- 名录抽取阶段的所有记录 `position`、`world` 为 null；后续由 `scripts/link_pois.py` 使用真实地理数据另行匹配。最终坐标和候选计数以 `data/pois.json` 及开发验收记录为准。未核实的位置保持空值。
