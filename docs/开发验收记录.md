# 方块长沙开发验收记录

基准日期：2026-10-14。交付阶段：首个可玩开发版。原 PRD 的全市景点、高还原、连续地图目标保持不变；本记录不代表完整 MVP 验收完成。

## 已交付和运行

源码位于项目根目录，静态构建位于 `dist/`。双击 `启动游戏.cmd`，或在根目录运行 `npm run dev`，再打开 `http://127.0.0.1:4173`。构建预览用 `npm run preview`，同一端口只开一个服务。

已有第一/第三人称、键盘行走/快走/跳跃、鼠标观察、全市地图搜索、九区县筛选、真实道路导航与沿路线前行、附近路人活动和招呼、晴日/黄昏/夜色、PNG拍照、浏览器本地相册、照片下载与进度保存恢复。地图及渲染库都在本地，运行不依赖外部 CDN。

## 实际验收证据

- `npm test`：22 项全部通过，包括真实比例、负数分块、真实图边寻路、断路拒绝、原件哈希、源引用、全部区块存在、交通站点误匹配过滤、CSV一致性、隧道过滤、桥上桥下层级和实际橘子洲大桥匝道接缝、行走地面与渲染三角面一致。
- `artifacts/browser-check.json`：在静态构建上测试，键盘产生实际位移，城区40名路人，地图搜索、拍照存相册、相册读取、刷新恢复进度通过；无未处理页面错误。
- `artifacts/photo.png`：通过真实下载按钮取得的1920×1080 PNG，检查PNG签名与图像尺寸；106,350 bytes。
- `artifacts/long-walk.json`：同一浏览器游戏移动/碰撞逻辑，以每次0.1秒加速模拟，不传送、不提高3m/s的游戏速度、不跳过水域/建筑/缺失区块。实走 **39,745.247m，跨50个实际区块**，路线完成，最终无阻拦；远郊位置在新世界中恢复成功。
- `npm run build`：通过。`artifacts/build-check.json` 对包括全部11,848个区块、Three.js模块与许可证在内的11,865个构建文件逐一比较SHA-256，与源码/数据一致。

长途测试从城区五一广场附近真实道路出发，到达靖港 OSM 登记代表点附近道路，距该点 **40.069m**。该点是命名面对象的代表位置，**不是已经核实的古镇入口，也不表示古镇建筑已完成重建**。测试证明城区到望城远郊的连续世界行走和恢复链条可运行；不把加速模拟当作在现实时间里等候了约3小时41分钟。

## 已修复的实走问题

1. 年嘉湖机动车隧道无明确步行许可，从步行图排除，保留其原始标签。
2. 地下涵管不再生成地表水域。
3. 源道路与建筑/无桥水面相交的连接从当前游戏导航排除；原始几何不改写。过滤结果是游戏通行规则，不能当作现实道路封闭结论。
4. 同一桥梁/匝道共享节点采用一致高程；连接道路平滑混合校正。桥上/桥下按所在层选择路面，普通同层道路按真实中心线选择。
5. 行走地面与实际可见三角面一致，道路开发高度贴合显示地形，避免脚部沉地。
6. 全市概览几何仅在2D显示层简化，地图底图缓存；完整3D地理分块和路由源几何保留。

## 未完成项与继续开发顺序

1. 当前有效A级景区逐项变更对账，以及所有非A级类别目录。原始附件只证明截至2025年1月底的基线；后续公开总数报道有冲突，不能从总数反推名称。
2. 107条缺失定位、九区县精确归属、同址范围、景区边界和真实可步行入口逐项核验。OSM代表点与名称精确匹配仍不是入口证明。
3. 松雅湖等断连数据；优先完成景区入口与园内步道核对，再扩大逐条全程实走覆盖。
4. 高度还原资产：标志建筑、街区立面、地标比例、招牌、核心室内、城市天际线、真实环境音。当前大部分建筑为公开轮廓和默认高度灰盒，39,128个建筑缺少明确高度；原创地标灰盒未通过PRD的85分还原标准。
5. 水下人行隧道内部、建筑上方高架的垂直碰撞尚未实现，相应冲突连接暂不通行。DEM与桥梁高度为公开数据开发模型，非测绘精度。
6. 真实设备长期帧率、内存、断网和存储配额、全市逐景/逐路线验收。当前浏览器证据来自Chromium/Playwright，不能代表所有硬件和浏览器。
