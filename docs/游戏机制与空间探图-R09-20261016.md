## 2. 新认识及撤回判断

### 机制、规则、输入与内容应能分别解释

Sicart提出一种分析用定义：机制是主体调用、用来作用于游戏状态的方法；规则限定其可能性和状态变化。一个按键不等于一种机制，多个操作也可能组成一个整体机制。作者明确这不是唯一正确定义，也不是要求用面向对象重写游戏。

项目推论：行走、观察、询问、构图等可以服务玩家自选经历，不能先按任务列表把它们分成主次。当前相同E键与交互范围是输入/条件层；路人的回答和玩家是否跟踪目的地是内容/效应层。以后描述改动时要能指出改变的是哪一层，避免“多加按钮/多写台词”冒充机制深化。

撤回：可以直接从功能模块或按键数量推导玩法；最频繁动作必然是唯一核心机制；形式模型能够决定所有实际玩法。该模型不解释全部美感、个人意义或游玩结果，不能排斥无明确任务的游览。

### 内容单元的条件与效果，比巨大分支树更容易说明依赖

Emily Short将storylet概括为内容、前提和效应；大小、选择策略及内部结构仍可不同。文章同时指出，严格依赖每一条历史分支的结构可能得不到这种方法的大部分收益。

项目推论：人物和场所内容需要说明何时适用、为什么出现、结束后什么改变、再次出现意味着什么。可借鉴其描述方法，无须引入完整叙事引擎。姓名/角色不同而其余上下文相同，是表现变化，不能直接算作新经历。条件与效果应连接现有世界/旅途状态，避免再造第二套事实。

撤回：只要随机选择更多台词就解决商铺/人物重复；给各景点复制一套任务就产生内容差异；读取一篇叙事方法就必须加入长剧情链。

### 人物可以有独立关注，玩家自主性不等于控制所有人

Jayanth讨论主角、玩家与NPC之间不同的能动性，并用自己的80 Days写作经验说明人物可以有独立动机和边界。她的主题与案例有鲜明立场，不能被当作所有游戏必须让玩家痛苦或失去控制的定律。

项目推论：路人有自己的步行、休息和看景，不需要都成为玩家的服务点；是否招呼/问路/合影和当前行为应能相互解释。普通人短暂出现也不必拥有长人物传记或任务链。这里采用独立关注与上下文的方法，不把作者的政治主题、惩罚或拒绝机制搬入长沙需求。

撤回：给NPC更多帮助玩家的选项就等于人物有主体性。R08已经撤回“40人移动=生活感”，本轮新增的是独立动机、关系边界与玩家控制的区别，不重复算作第一次发现。

真实长沙的建筑、路线和历史事实仍须来源核对；虚构路人的个人看法不能替代事实，也不能将80 Days的虚构世界写法理解为现实资料无需正确答案。

### 找路包括理解自己在哪，也包括决定怎么走

Wayfinding区分定位与导航，强调玩家可利用空间而非总沿设计者指定路线；Circulation区分主次、公共/私密、水平/垂直以及空间用途和形式连接。教程引用的城市理论不是本轮已经读过的原著。

项目推论：地址和小地图要支持定位，目标与路线支持导航；路口、入口、层位、来路与回路共同决定可用性。清晰地看见地标不保证能走到那里。地铁/庭院等应同时核对可见信息、真实连接和脚下通行，而不仅仅核对一个点或一个漂亮角度。

撤回：清楚箭头/最短路就是完整空间设计；自由探索需要删掉地图；所有通路都应把玩家送回同一条“正确路线”。竞技关卡的1—3 lane等例子不成为长沙街网规则；反wayfinding的混乱空间也不成为真实城市目标。

### 空间构图与镜头构图有区别，但不能简单选边

关卡书反对用一个截图和引导线推断行为，并明确此立场非行业共识。追读Bellard本人页面后，她的准则同时包含空间电影性、视觉叙事、交互、美感和制作可行性，还讨论移动、时间、相机空间和跨部门使用。

项目推论：构图可帮助画面表达和空间阅读，不能保证玩家按同一路线行动；玩家控制镜头时，空间需要在接近、通过、回望和不同层位仍成立。单张照片有价值，连续游览也有独立证据要求，两者不能互相取消。

撤回：只要一个机位漂亮就完成场景；或者因读到批评就完全放弃构图。书中99%、97%等数字并非本项目实测，不能加入验收。没有把Bellard书单和讲座目录算成全部精读，也没有据摘要宣布已掌握Rockstar完整流程。

## 4. 已落实到制作架构

已更新[制作方案与实施架构](游戏制作方案与实施架构-20261015.md)当前方法正文，而非只在文末追加资料名单：

- 机制/规则/输入/内容分别说明，方法用于真实变化，不能要求所有内容机械填同一模板。
- 地理事实标识、人物内容单元、运行状态和渲染表现分别有责任；内容条件/效应引用现有事实，不生成第二套城市。
- 空间联合检查路线/入口/层位与连续视图；单图验收和运动验收各有范围。
- 内容可用性、人物独立关注与可中断恢复有明确说明；不从理论推导额外剧情/奖励或引擎迁移。
