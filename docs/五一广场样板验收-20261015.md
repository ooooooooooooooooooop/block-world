# 五一广场样板实际验收 · 2026-10-15

当前状态：**功能验证通过，还原质量未接受（FUNCTIONS_PASS_FIDELITY_NOT_ACCEPTED）**。这是原有连续长沙世界里的可玩样板，不能计作PRD的85分还原、盲辨或全市MVP通过。

## 直接体验

打开 http://127.0.0.1:4173 ，或双击项目的 `启动游戏.cmd`。点击“开始我的漫游”进入五一广场；“继续上次的旅程”保留原存档位置。

WASD行走，Shift快走，拖动观察，E与近处路人对话，C摄影，F快门，P相册，Esc关闭。摄影可切第一/第三人称、焦距、画幅、日夜与路人；原图下载为PNG。测试使用独立浏览器目录，不触碰用户日常浏览器存档。

## 已落地的实现

- `scripts/prepare_data.py`：去掉300米截断；新增高度字段溯源、只迁移高度和校验回滚入口。1462块/44523条建筑记录迁移；原始OSM、非高度几何/地形/道路/水域保持。
- `src/wuyi-data.mjs`：从原件提取真实五一广场、双塔、IFS复杂商场和平和堂等10个空间锚点；不挪动地标间距。
- `src/wuyi.mjs`：原创像素材质、真实轮廓立面分格、局部街景与昼夜窗灯；参考照片只指导制作，不作为游戏贴图。
- `src/world.mjs`：去掉渲染600米上限、路人合批/行为、附近对话、相机取景与几何可见性检查；局部地面平顺和边界渐变明确标记为开发近似。
- `src/app.mjs`及界面：摄影控件与焦点退出、存储偏好、路人对话；以不超过50毫秒的小步处理帧间时间，修复低帧率下慢走及浮点残步清除碰撞反馈。
