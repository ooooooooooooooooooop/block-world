# 移速与鼠标视角修复

2026-10-15（Asia/Shanghai）。针对用户反馈的“移速太慢、不能用鼠标控制视角”实际修改代码并验证。

- 步行4.8→8米/秒，快走8.5→16米/秒，分别提高约67%和88%；仍使用原城市坐标和连续地图。加快松键减速，保持停步可控。
- 视角改用标准mousedown/mousemove/mouseup；保留点击锁定转向，支持按住鼠标左键或右键拖动，包括摄影模式；右键不弹出菜单。画布可获得键盘焦点，提示明确写出操作方式。
- Esc、打开面板和窗口失焦会释放输入，清除积累的视角增量。提高速度后，碰撞检查沿实际移动段每不超过14厘米采样，避免仅看终点而越过细栏杆、立柱。

## 新鲜验证

完整Chromium、1440×900。普通浏览器鼠标锁定、第一/第三人称左右键拖动、摄影拖动及PNG下载、Esc释放后点击设置均实际操作通过。另明确禁用requestPointerLock，验证左右键拖动仍可用。仅投递标准MouseEvent的兼容探针中，旧版转向0，新版100像素产生0.26弧度，垂直40像素产生-0.08弧度；这是声明的脚本事件探针，不冒充物理输入或内置浏览器实测。

约2秒实际键盘输入：步行行程由9.782增至16.299米，快走由16.396增至31.295米。准确按键时长和位置记录在回执，不把等待时长当精确计时器。

真实细柱碰撞使用5种起步距离和50毫秒模拟步长验证，全部停止在柱外；新速度下2号口Shift+W下行、Shift+S返回及可见地面接触通过。69项Node测试通过；仅增量同步4个变化文件到已有dist，18个源码/打包/HTTP文件哈希一致，其余素材与原始地图保持。

内置浏览器自动化通道本轮超时，未能直接检视用户当前那一页；不能确定该页具体为何没有视角输入。上述验证分别覆盖正常锁定和锁定不可用的输入路径，不冒称内置浏览器已直接复测。
