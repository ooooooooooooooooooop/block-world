# 方块长沙

按 [产品需求文档](长沙方块城市漫游-PRD.md) 开发的浏览器三维城市游览游戏。目标是覆盖长沙全市景点，在真实地理尺度的连续世界里从城区走到远郊，遇见路人并拍照。

最新操作修复：步行 **8米/秒**、Shift快走 **16米/秒**；按住鼠标左键或右键拖动视角，点击画面可锁定鼠标，Esc释放。标准鼠标事件和锁定不可用的兼容路径已验证，见[操作修复记录](docs/移速与鼠标视角修复-20261015.md)。

当前五一广场已加入可行走中层廊道、上下层连接、实际生效的平和堂弧面/屋顶/沿街开间、开放钢廊及修正后的园路。人物改为更完整的原创方块模型，中文界面/站牌字形与字号重做；跟随镜头、走停、转身、贴墙及Esc鼠标释放已实际验证。

此前美术样板验收快照：正常键盘121.061米，中层行走与存档恢复、1/2/4/8四口往返、8张1920×1080相机原图通过；40名路人观察600.016秒并核对可见地面。69项测试、11,848分块构建及18个源/构建/HTTP哈希一致。[原图/字体前后/操作视频](artifacts/wuyi-v19-20261015/index.html)与[当前验收](docs/五一广场多层空间与视觉手感验收-20261015.md)可直接查看。

6C/6D已有独立命名地图点位，但精确地面门心、层位和连接仍未全部核实，5/7等其他入口未齐。PRD v1.9保留全市目标和禁止真人，**还原尚未通过85分标准**：完整多层庭院、逐店真实立面、全部入口、绿化街具逐点和同机位配准仍未闭合。功能通过不代表完整MVP完成。

## 启动

当前工作目录已安装项目依赖并生成地图，双击 `启动游戏.cmd` 即可。也可在本目录运行：

```powershell
npm run dev
```

打开 http://127.0.0.1:4173 。服务仅监听本机。终端按 Ctrl+C 关闭；无需注册或在线账号。

复制到新电脑后先运行 `npm install` 安装依赖。

## 操作

| 操作 | 按键 |
| --- | --- |
| 行走 | W/A/S/D 或方向键 |
| 快走 / 小跳 | Shift / 空格 |
| 观察 | 按住左键或右键拖动；点击场景锁定鼠标 |
| 释放鼠标、关闭面板 | Esc |
| 第一/第三人称 | V |
| 地图 / 相机 / 相册 | M / C / P |
| 摄影快门 | F，或点击快门按钮 |
| 与附近路人打招呼 | E |

首次看样板请点“开始我的漫游”，进入五一广场；“继续上次的旅程”会恢复原存档位置。摄影面板可切风景/合照、焦距、画幅、昼夜和路人；滑块保持焦点时 C/Esc 也能退出。

地图支持搜索、九区县筛选、缩放和步行路线。导航仅使用数据中存在的道路边；路网未连接时会说明原因。远郊保持真实距离，途中可保存。照片可下载 PNG，也可存在当前浏览器的相册中；清理浏览器数据会影响本地相册，建议下载留存。

## 数据与重建

- `data/pois.json`、`data/pois.csv`：景点台账与逐项来源。原始附件基线、后续变化、PRD候选和公开地图补充项分开标记。
- `data/sources.json`：来源、原件哈希、解析方法和范围限制。
- `data/world-manifest.json`：连续世界范围、起点和全部分块索引。
- `data/chunks/`：按真实地理位置划分的 1024 米分块，包括地形、道路、建筑与水系。
- `data/graph.json`：保留 OSM 共享节点关系的道路图，不人为补齐断路。
- `data/data-report.json`：地理来源、数量、覆盖范围、缺失项和限制。
- `docs/景点清单核对.md`、`docs/景点增量审计.md`：名录核对与日期变化。
- `docs/定位核对.md`、`data/extra-geocodes.json`：原始命名对象候选与同名误匹配检查。候选不会不经筛选地变成景点坐标。
- `docs/开发验收记录.md`：本轮实际验收、通过范围与待完成项。

原始公开资料保存在 `data/raw/`，不会由本地 HTTP 服务公开。

首次重建需 Python 3.12 或兼容版本及网络访问：

```powershell
python -m pip install --target .python-deps -r requirements.txt
python scripts/download_region.py
python scripts/prepare_pois.py
python scripts/prepare_data.py
python scripts/optimize_map.py
python scripts/extract_named_pois.py
python scripts/link_pois.py
```

已有下载会从缓存读取。全量地理处理、DEM下载和分块生成可能需要数分钟。准备失败时保留原始错误，不将缺失地形替换成虚构数据。

也可以运行 `npm run data` 按上述顺序执行。仅调整地理处理规则且原始快照未变时，可用 `python scripts/prepare_data.py --skip-extract --no-fetch-dem` 重用已裁剪原件和 DEM 缓存，再运行后面的概览优化与定位合并步骤。

## 验证与构建

```powershell
npm test
npm run build
```

`dist/` 是可静态托管的构建目录，包含 Three.js 本地文件，运行时不依赖外部 CDN。浏览器交互验收脚本 `tests/browser.mjs` 需要可用的 Playwright 和 Chromium；通过 `PLAYWRIGHT_PATH` 指定已有 Playwright 包目录后，启动本地服务再运行该脚本。证据输出到 `artifacts/`。

运行 `npm run preview` 可在本地检查 `dist/`，同一端口只启动一个服务。`node scripts/check_routes.mjs` 检查远郊真实路网和地形覆盖；`tests/long-walk.mjs` 使用浏览器内同一移动与碰撞逻辑加速模拟完整路线，不传送、不提高游戏内速度。通过 `WALK_TARGET` 选择已有定位的景点名称。它验证模拟行走，不代表在现实时间里等待了数小时，也不代表现实道路通行许可已核实。

## 当前质量边界

官方名录的完整抽取不等于截至今天所有变更均已核完；公开地图的命名对象不等于已经核实景区入口和公共步行权限；OSM快照裁全域不等于现实中每条道路均被完整绘制。

道路中心线、建筑轮廓、水系与地形有真实数据依据；缺少高度标签的普通建筑使用明确的默认体量。树木依据土地类型生成氛围表现，位置并非逐树测量。桥梁高程是基于DEM的开发模型，非测绘结果。无明确步行许可的机动车隧道从步行图排除；地下涵管不生成地表水域。当前水下人行隧道内部、建筑上方高架的三维碰撞尚未实现，相应冲突连接暂不能通行。景点灰盒、核心室内、人行入口与逐景还原仍须按PRD继续制作和验收。

五一广场样板对粗DEM中的屋顶/旧高架起伏做了局部平顺校正，并在样板边缘渐变接回地形；这是照片指导的开发近似，不是实测高程。绿化/街具的具体位置、部分立面和广告内容是原创近似，尚未通过逐机位还原评审；原始地图和全市道路数据保留。

行走地面采样采用与渲染一致的三角面插值；道路的开发高度贴合可见地形，避免不同公开高程采样造成脚部沉地。这个处理用于场景连续性，不代表道路测量高程已完成核验。
